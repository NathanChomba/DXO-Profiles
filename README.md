# DXO community profiles

Controller setups for DXO, shared by players and reviewed before they go
live. Several setups per game is normal: pick the one that fits how you play.

## Use them

Open DXO's **Community** page. Newer versions of DXO connect here by
themselves. On older ones, click the gear button and paste the raw address
of this repository's `index.json`:

    https://raw.githubusercontent.com/<owner>/dxo-profiles/main/index.json

DXO only downloads from here. Nothing on your PC is uploaded, and any
"open a program" button is removed from a profile before it's saved.

## Share yours

See [CONTRIBUTING.md](CONTRIBUTING.md). Short version: export the profile
from DXO, add it under `profiles/<game>/`, list it in `index.json`, and open
a pull request. No profile to share? Use **Issues > New issue > Request a
profile**.
